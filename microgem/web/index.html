Language reference

Addresses: A0.3 is bit 3 of word 0 in table A. Inputs are A, outputs are B, workspace is G H L N O U, retained workspace is R W.

Contacts: A0.0, NOT A0.0, RISE A0.0, FALL A0.0, TRUE, joined with AND, OR and brackets. Word comparisons: G1 GE 5 (EQ NE GT LT GE LE).

Outputs: a bit address is a coil; SET B0.0, RESET B0.0; DELAY 2.5s G0.1; COUNT 10 G1 G0.2; CLEAR G1; OUT 42 G2; ADD G1 G2 G3 (also SUB MULT DIV). Separate several with commas.

This notation is provisional until we find the original GEM 80 programming manual (T391).
